# Política de seguridad

## Versiones mantenidas

Este repositorio representa un proyecto académico y de portafolio. La rama `main`
recibe las correcciones disponibles.

## Reportar una vulnerabilidad

No publiques credenciales, datos personales ni detalles de explotación en un issue.
Utiliza la opción **Report a vulnerability** de la pestaña **Security** del repositorio
para enviar un reporte privado.

Incluye una descripción, pasos mínimos para reproducir el problema, impacto estimado y
una propuesta de mitigación si la tienes. Los reportes se revisarán antes de publicar
información técnica.
